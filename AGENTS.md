# OSDCloud Demo

Keep this foundation small. Keep the installation function and Windows settings inline in OSDCloud_Start.ps1, in the [OS] section. Do not replace it with a module launcher. OSDCloudModules/Module.psm1 supplies OOBE helpers and the app list only. Documentation is Danish; conversation follows the user's language.

Read README.md and STATUS.md before changes. Startup is automatic with no initial DEMO confirmation; keep the VM and single-target-disk guards. Use OSDCloud's native wipe/partition steps on RAW or previously partitioned disks; do not add a separate Clear-Disk/diskpart wipe. The agreed demo is Windows 11 25H2 x64 English Enterprise Evaluation from the user-supplied LAN ISO, online Graph registration with the Group Tag selected by the technician at Windows OOBE, verification, exact allowlisted app removal, then restart to OOBE. Use the user-requested AutopilotOOBE JSON settings; registration is still online through the AutopilotOOBE UI. Do not add autologon, tenant secrets, unrelated helpers, frameworks or generated configuration layers.

This public repository contains demo code only. Never commit hashes, tenant credentials, device identities or logs. Do not execute installation, app removal or registration as a host-side test. Keep unrun Windows/Hyper-V/tenant checks explicit. Follow /home/ax/dev/AGENTS.md when available; keep this repository the authoritative home of demo code.
